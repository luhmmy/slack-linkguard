# Quick Commands to Push to GitHub

## Step 1: Create Repository on GitHub
Go to: https://github.com/new
- Name: `slack-linkguard`
- DO NOT initialize with README

## Step 2: Run These Commands

```powershell
git remote add origin https://github.com/luhmmy/slack-linkguard.git
git branch -M main
git push -u origin main
```

## Step 3: View Your Repository
https://github.com/luhmmy/slack-linkguard
